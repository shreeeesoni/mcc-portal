# mcc-portal

Static preview site for the MCC Portal UI (seat allotment portal). This repository contains a small static site under /docs that reproduces the UI blocks captured in the screenshot you provided.

What is included:

- docs/index.html — Static HTML preview of the portal UI and screenshot placement.
- docs/css/styles.css — Styles used by the preview page.
- docs/assets/screenshots/README.md — Placeholder instructions to add the screenshot image.

To publish the site via GitHub Pages:

1. Go to Settings → Pages in the GitHub repository.
2. Choose the `main` branch and `/docs` as the source.
3. Save. GitHub will publish the site at `https://<owner>.github.io/<repo>/`.

To show the real screenshot on the page, upload the original screenshot image to `docs/assets/screenshots/screenshot1.png`.
